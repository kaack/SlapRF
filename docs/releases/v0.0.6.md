## Highlights

Redesigned desktop and mobile UI across Practice and Race workspaces, featuring a unified race format editor, one-click practice lap invalidation (scratching), and accurate section split handling across session pauses.

## New Features & Improvements

- **Desktop & mobile workspace redesign**: Streamlined navigation, responsive workspace tabs, and cleaner Pilot, Practice, and Race layouts across desktop and phone viewports.
- **Unified race format editor**: Combines visual stage/round graph editing and table configuration in a single Race Setup view.
- **Practice lap scratch (invalidation)**: Click any recorded practice lap to scratch or restore it, automatically recomputing personal bests, averages, and section badges.

## Bug Fixes

- **Section splits across pauses**: Prevents paused session intervals from inflating in-progress section split times when resuming practice.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), and Linux (`amd64` & `arm64`).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (`v0.1.7`, wire protocol `v2`, no reflash required from `v0.0.4`+).
