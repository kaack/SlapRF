### ✨ What's New

| Feature | What Changed |
| :--- | :--- |
| **Non-Destructive `FT` Model Copies** | Click **Fine-Tune** on **`SlapRF Base`** or any trained model in **Practice -> AI Training** to save a new **`<Model> FT`** copy (followed by **`FT (1)`**, **`FT (2)`**, and so on) while keeping the original model untouched. |
| **Untrained Base Model Selector** | Select any untrained model in **AI Training** to choose **Empty (train from scratch)** with **Train**, or pick an existing trained model in **Base model** to **Fine-Tune** into your new named model. |
| **Automatic Selection After Fine-Tuning** | Select newly created fine-tuned copies automatically in **AI Training** as soon as training completes, with full rename and delete controls. |

---

### 🛠️ Improvements

- **Built-In `SlapRF Base` Recovery** · Migrate any previously overwritten built-in model into **`SlapRF Base FT`** automatically on startup so the original `1P` **`SlapRF Base`** model is always available.
- **Mobile AI Training Layout** · Keep **Base model** and on-device labeler controls aligned cleanly on narrow phone screens without clipping.

> **No timer or bridge reflash needed** · Existing `v0.0.8+` XIAO ESP32-C5 timers and `v0.2.3` ESP32-P4 PoE Bridges are 100% compatible with `v0.0.19`.
