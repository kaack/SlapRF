## Highlights

Introduces the versioned, resource-oriented `/v1` REST and `/v1/ws/stream` WebSocket API, launches the standalone Hugo documentation site at `slaprf.app/docs/` with an embedded WebSerial firmware flasher and interactive OpenAPI 3.1 / AsyncAPI 3.0 explorers, and adds dark-mode XIAO ESP32-C5 hardware setup diagrams.

## Breaking Changes

- **REST & WebSocket API moved from `/api/*` to `/v1/*`**: External scripts and integrations must update HTTP endpoints from `/api/...` to resource-oriented `/v1/...` routes (for example `GET /v1/state`, `GET /v1/status`, `PUT /v1/timing/arm`) and WebSocket stream connections from `/api/ws` to `/v1/ws/stream`. See the interactive specs at `https://slaprf.app/docs/reference/api-reference/`.

## New Features

- **Documentation site (`slaprf.app/docs/`)**: Added getting-started guides, DIY XIAO ESP32-C5 assembly and LED reference pages, Practice and Race Control workflows, and an embedded browser WebSerial firmware flasher (`cmd/build-docs`).
- **Interactive API reference**: Published OpenAPI 3.1 (`openapi.yaml`) and AsyncAPI 3.0 (`asyncapi.yaml`) specifications with built-in request/schema explorers.

## Improvements

- **Dark & light hardware illustrations**: Added matched dark-slate (`#0f172a`) and light illustrations for Bluetooth Hub Mode, USB Hub Mode, and XIAO ESP32-C5 pinout/antenna/LED/BOOT callouts.
- **LapRF `:5403` server naming**: Standardized UI and API terminology around the built-in LapRF 8-Way TCP (`:5403`) server for external timing clients (LiveTime, FPVTrackside, RotorHazard).

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), Linux (`amd64` & `arm64`), and Android (`arm64-v8a` APK).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (USB Hub & Spokes) and `slaprf-xiao-c5-ble.bin` (Bluetooth Hub), wire protocol `v2`.
