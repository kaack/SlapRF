## Highlights

Initial release (`v0.0.1`) of **SlapRF**, a standalone FPV drone lap timing, multi-gate section split, and race management application with DIY Seeed Studio XIAO ESP32-C5 field timer firmware.

## New Features

- **Multi-hardware timing support**:
  - **SlapRF (USB)**: USB-C Hub (`H1`) and up to 6 wireless `2.4 GHz` ESP-NOW Spoke timers (`T1`-`T6`) built on off-the-shelf Seeed Studio XIAO ESP32-C5 boards.
  - **RotorHazard (USB & Network)**: Direct USB serial node support (`FPVGateC5` / `RX5808`) and LAN HTTP / Socket.IO integration (`:5000`).
  - **ImmersionRC LapRF 8-Way**: Ethernet TCP (`:5403`) client integration and built-in LapRF `:5403` output server.
- **Practice sessions & section analytics**:
  - Live practice leaderboard with `S1`, `S2`, and `S3` section splits, theoretical best lap calculation, and bottleneck analysis.
  - Real-time `5.8 GHz` RSSI charts, per-pilot enter/exit hysteresis calibration, and crossing guardrails.
  - Spoken lap callouts and start horns with Web Speech and offline Piper neural voices.
- **Race & tournament management**:
  - Visual Stage & Format Editor supporting Double Elimination, Single Elimination, Controlled Qualifying, Open Qualifier, Points Mains, Chase the Ace, and custom multi-stage graphs.
  - Live Race Control cockpit with automated countdowns, marshal scoring controls, and post-heat RSSI waveform review.
  - MultiGP Chapter integration to import rosters/schedules (including ZippyQ) and upload confirmed round and lap results.
- **Track, flasher & hardware diagnostics**:
  - Track editor with gate ordering and per-gate timing rule overrides.
  - Built-in XIAO ESP32-C5 USB Firmware Flasher (`SLAPRF02` binary patching with fingerprint preservation) and Debug view (`50 Hz` Signal Over Time, `5.8 GHz` Spectrum Scan, Waterfall spectrogram, and USB serial console).
- **Single-file local server & browser demo**:
  - Cross-platform Go executable for Windows, macOS, and Linux (`amd64` / `arm64`) with embedded `bbolt` storage (`slaprf.db`), optional LAN access (`-lan`), and HTTP Basic Authentication, plus the interactive browser demo at `https://slaprf.app`.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), and Linux (`amd64` & `arm64`).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (USB Hub & Spokes).
