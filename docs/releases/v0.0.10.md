## Highlights

Disables standalone Progressive Web App (PWA) installation across mobile and desktop browsers so users do not install a browser shortcut alongside the native SlapRF Android APK or desktop binary, while preserving `sw.js` offline asset caching.

## Improvements

- **Disable standalone PWA installation**: Set `"display": "browser"` in `web/manifest.webmanifest`, removed `mobile-web-app-capable` and `apple-mobile-web-app-*` meta tags from `web/index.html`, suppressed `beforeinstallprompt` banners in `offline.ts`, and removed the TopBar PWA install button and popover. Repeat browser visits still cache the WASM simulator and neural voice assets through `sw.js`.
- **Automated GitHub release notes**: Updated `.github/workflows/release.yml` to publish structured release notes from `docs/releases/<tag>.md`.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), Linux (`amd64` & `arm64`), and Android (`arm64-v8a` APK).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (USB Hub & Spokes) and `slaprf-xiao-c5-ble.bin` (Bluetooth Hub), wire protocol `v2` (compatible with `v0.0.8` and `v0.0.9` timers, no reflash required).
