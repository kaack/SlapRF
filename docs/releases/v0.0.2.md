## Highlights

Upgrades XIAO ESP32-C5 RF capture and wire encoding to `0.5 dB` resolution (firmware `v0.1.6`), adds a zero-lag plateau peak detector with continuous background RSSI auto-calibration, and introduces browser-native WebSerial flashing alongside a `20 Hz` Raceband network survey.

## Breaking Changes

- **Firmware wire protocol `v2` (`0.5 dB` window frames `0x60` / `0x61`)**: Reflash both the Hub (`H1`) and all Spoke timers (`T1`-`T6`) to `slaprf-xiao-c5.bin` (`v0.1.6`) so all boards use matching `0.5 dB` sliding-window frames.

## New Features

- **Browser-native WebSerial flasher**: Flash and provision XIAO ESP32-C5 Hub and Spoke boards directly from Chromium browsers without external Python tools, preserving existing `SLAPRF02` board fingerprints.
- **Background RSSI auto-calibration**: Continuously tracks per-pilot noise floor and crossing peaks across live laps to calibrate enter and exit thresholds automatically.
- **Network `20 Hz` live RSSI & Raceband survey**: Streams live Hub/Spoke channel bars on `#/network` and adds a temporary 8-channel `R1`-`R8` band survey mode.

## Improvements & Bug Fixes

- **Zero-lag plateau peak detector**: Accurately centers gate crossing timestamps across flat saturated close-range VTX pass plateaus.
- **Cold-boot USB flush & mode-switch sync**: Flushes stale USB serial bytes on connect and resets `HubFrameDecoder` slot state cleanly when switching timing hardware modes.
- **Default `15 s` signal chart window**: Sets the live RSSI chart default window to `15 s` for clearer pass curve inspection.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), and Linux (`amd64` & `arm64`).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (`v0.1.6`, wire protocol `v2`, reflash required when upgrading from `v0.0.1`).
