## Highlights

Improves gate crossing accuracy under multipath reflections with a 2-pole multipath-bridging RSSI envelope filter and valley-aware threshold auto-calibration.

## Improvements & Bug Fixes

- **2-pole multipath-bridging RSSI envelope**: Bridges brief destructive multipath nulls during a gate pass so a single physical crossing is never split into duplicate detections.
- **Valley-aware auto-calibration**: Anchors exit thresholds above inter-pass noise floors while preventing deep multipath dips inside a pass from prematurely re-arming the detector.
- **Fixed-width `dBm` readouts**: Stabilizes numeric RSSI labels in tables and legends so live readings do not shift layout width as digits change.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), and Linux (`amd64` & `arm64`).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (wire protocol `v2`, compatible with `v0.0.2` timers without reflashing).
