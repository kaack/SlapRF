### ✨ What's New

| Feature | What Changed |
| :--- | :--- |
| **Diagnostic Logs (`slaprf.log`)** | Record user actions, laps, race events, and hardware links to a rolling `slaprf.log` file on desktop and Android (or an in-memory buffer in Demo Mode). |
| **Settings Diagnostics** | Switch log levels (`ERROR` to `TRACE`), download `.log` files, or clear logs directly from **Settings**. |
| **Logs REST API** | Query, download, configure, and clear diagnostic logs via `/v1/logs`, documented under **Logs** in the REST API reference. |

---

### 🛠️ Improvements

- **Simulated Log Tagging** · Tag simulated actions, crossings, and laps with `[SIM]` to separate them from real hardware.
- **Bluetooth Startup Reconnect** · Retry remembered Bluetooth Hub connections automatically when starting or updating the app.

---

### 🩹 Bug Fixes

- **Bluetooth Spoke Signals** · Fixed Spokes showing `0 samples` and missing **Signals** traces when initial Hub announcements drop.
- **Practice Sample Counters** · Fixed **Network** gate sample counters resetting during active **Practice** sessions.
- **Bluetooth Pairing Keys** · Preserve and recover Bluetooth Hub pairing keys across app restarts and data resets.

---

> [!TIP]
> **No reflash needed** · Existing `v0.0.8+` XIAO ESP32-C5 timers are 100% compatible with `v0.0.16`.
