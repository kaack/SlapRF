### ✨ What's New

| Feature | What Changed |
| :--- | :--- |
| **Native iOS & iPadOS App** | Sideload SlapRF on iPhone and iPad via Sideloadly, SideStore, AltStore, or Xcode for wireless Bluetooth Hub, PoE Bridge, LapRF, RotorHazard, and Wi-Fi Pocket Server timing. |
| **Android Startup Diagnostics** | Save `Downloads/slaprf-startup-log.txt` automatically and show a **Share Log** screen if the Android app ever fails to open. |
| **Demo Practice RSSI Waveforms** | Include pre-baked multi-gate RSSI curves in all showcase **Practice** sessions so clicking any demo lap displays full signal traces immediately. |

---

### 🛠️ Improvements

- **iOS & iPadOS UI** · Hide USB-only controls automatically and add native **iOS System Voice** callouts.
- **PoE Bridge Topology** · Show **PoE** transport badges on Hub cards in mobile **Network** views.
- **Troubleshooting Guide** · Document how to collect `slaprf-startup-log.txt` on Android when opening a GitHub issue.

---

### 🩹 Bug Fixes

- **Android 17 Sideloading** · Launch the app cleanly even when Android blocks background foreground services for browser-installed APKs.
- **Debug Connection Menu** · Open the **Disconnect** menu when tapping a PoE-bridged Hub pill on the **Debug** page.

> [!TIP]
> **No timer or bridge reflash needed** · Existing `v0.0.8+` XIAO ESP32-C5 timers and `v0.2.3` ESP32-P4 PoE Bridges are 100% compatible with `v0.0.20`.
