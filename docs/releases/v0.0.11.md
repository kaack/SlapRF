## Highlights

Enables native `CoreBluetooth` Bluetooth LE Hub connections in the macOS release binaries (`slaprf-macos-arm64` and `slaprf-macos-amd64`), bringing SlapRF Bluetooth Hub timing parity across Windows, macOS, Linux, and Android.

## New Features

- **macOS Bluetooth LE Hub support (`slaprf_ble`)**: Compiled `slaprf-macos-arm64` and `slaprf-macos-amd64` natively on macOS with `CGO_ENABLED=1` (`MACOSX_DEPLOYMENT_TARGET=13.0`), embedded `__TEXT,__info_plist` (`NSBluetoothAlwaysUsageDescription`), and ad-hoc Mach-O code signing so MacBooks discover, pair (`AUTH`), and stream `50 Hz` RSSI telemetry from XIAO ESP32-C5 Bluetooth Hubs in any browser.

## Improvements

- **CI linkage verification**: Added `otool` checks in `.github/workflows/release.yml` verifying `CoreBluetooth.framework` linkage and embedded `NSBluetoothAlwaysUsageDescription` metadata on every macOS release artifact.
- **macOS installation guide**: Updated `slaprf.app/docs/getting-started/installation/` with macOS Bluetooth permission notes.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), Linux (`amd64` & `arm64`), and Android (`arm64-v8a` APK).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (USB Hub & Spokes) and `slaprf-xiao-c5-ble.bin` (Bluetooth Hub), wire protocol `v2` (compatible with `v0.0.8` through `v0.0.10` timers, no reflash required).
