## Highlights

Fixes silent announcer callouts on initial page load across macOS and Windows, eliminates horizontal X-axis jumping and background polling stalls on live signal charts, and adds a 3-way documentation theme switcher (`Light` / `Auto` / `Dark`) with redesigned `2x` Retina dark and light `README` screenshots.

## Improvements

- **Documentation theme switcher**: Added a 3-way `Light` / `Auto` / `Dark` selector to `slaprf.app/docs/` that follows the browser `prefers-color-scheme` setting by default until overridden by the user.
- **`README` & `2x` Retina screenshots**: Replaced overview copy with Simplified Technical English and added paired `2880 px` dark and light screenshots for Practice section splits, Tournament Brackets, and Race Control.
- **Docs-only CI deployment**: Added `.github/workflows/docs.yml` to publish documentation updates to `slaprf.app/docs/` in ~35 seconds without rebuilding firmware or WASM artifacts.
- **WASM Demo lightweight status polling**: Switched `ApiClient.pollStatus()` in browser WASM Demo mode to `/v1/status?lite=1` while the live event stream is active, avoiding full tournament and lap history JSON serialization every 2 seconds.

## Bug Fixes

- **Voice announcer silent on first load (macOS & Windows)**: Detected browser autoplay rejection (`speechSynthesis` `not-allowed`) on initial load, unlocked Web Speech and Web Audio on the first user click/key/touch gesture, re-spoke blocked callouts immediately, and fell back to system speech while uncached Piper neural voice models download.
- **Debug signal chart X-axis jumping**: Fixed `Auto X` on `#/debug` ("Signal over time & channel noise") to hold a deterministic `15 s` window instead of recomputing window width from noisy wall-clock sample arrival intervals (`18 s` to `20 s` flips).
- **Practice & Race Signals rhythmic stutter after visiting Debug**: Stopped `DebugView` animation loops and background status callbacks in `onDeactivate()` and read live pilot/timer state directly from `AppStore` in memory instead of polling `GET /v1/state` every `200 ms`.
- **Zoomed-out RSSI chart decimation**: Anchored `PilotRssiChart` zoomed-out peak buckets to immutable sample timestamps (`timestampUs`) and configured `windowUs` rather than 8-bit wrapping sequence numbers.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), Linux (`amd64` & `arm64`), and Android (`arm64-v8a` APK).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (USB Hub & Spokes) and `slaprf-xiao-c5-ble.bin` (Bluetooth Hub), wire protocol `v2` (compatible with `v0.0.8` timers, no reflash required).
