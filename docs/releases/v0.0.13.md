## Highlights

Adds independent per-practice and per-race track layouts and timing rules, splits ImmersionRC LapRF 8-Way into dedicated Network (`TCP :5403`) and USB (`115200` baud) modes, adds Bluetooth Hub pairing/remember/forget controls and headless Raspberry Pi LAN/BLE support, and delivers GPU-accelerated mobile navigation, keyboard drawers, and per-timer signal calibration.

## Breaking Changes

- **REST API hardware & track routes (`/v1/*`)**: Hardware transport routes are now grouped under `/v1/slaprf/{usb,bluetooth}/*`, `/v1/laprf/{network,usb}/*`, `/v1/rotorhazard/{network,usb}/*`, and `/v1/sim/{slaprf,laprf,rotorhazard,multigp}/*`. Track layout and timing rule configuration moved from global track state to per-session (`/v1/practice/sessions/{id}/{track,rules}`) and per-race (`/v1/race/sessions/{id}/{track,rules}`) endpoints. Update external API scripts against the OpenAPI 3.1 specification at `/docs/specs/openapi.yaml`.

## New Features

- **Per-session and per-race tracks & timing rules**: Replaced the single global **Track** screen with dedicated **Track** tabs inside every Practice session and Race event. Each session and race stores its own gate order, Start / Finish assignment, track-wide timing rules, and per-timer overrides independently, locking read-only once a race completes.
- **LapRF 8-Way Network vs. USB modes**: Split ImmersionRC LapRF 8-Way into **LapRF 8-Way (Network)** (`TCP :5403` with LAN discovery and manual IP entry) and **LapRF 8-Way (USB)** (`115200` baud CDC serial) in the **Network** timing system selector.
- **Bluetooth Hub Pair, Connect, Cancel & Forget**: Added explicit **Pair Device** discovery, one-tap reconnect to a remembered Bluetooth Hub, live connection status with **Cancel**, and wireless **Forget Device** unbonding from **Network**.
- **Unified Network connection dialogs & RotorHazard sign-in**: Added an inline **Timing system** selector on **Network** (locked while connected to prevent mid-session mode switches), unified LAN/USB device picker dialogs, multi-device disconnect management, and an inline RotorHazard authentication modal that clears rejected credentials automatically.
- **Zero-config headless Linux & Raspberry Pi mode**: Running `slaprf` over SSH or `systemd` on Linux without a desktop display now enables `-lan` (`0.0.0.0:8090`) automatically, prints `.local` and LAN URLs, and powers on the active BlueZ Bluetooth controller on startup.

## Improvements

- **Per-timer Signals calibration & mobile layout**: Scoped **Signals** calibration, clear-calibration, and **Fine-tune** actions to individual timers, hid **Calibrate** until valid pass data is recorded, added a calibrating spinner, and displayed pilot VTX channels aligned inside **Signals** pilot pills.
- **Mobile navigation & physics-driven tab swiping**: Matched horizontal swipe order to the mobile bottom bar (`Races` -> `Practice` -> `Pilots` -> `Network` -> secondary routes), added a vertical 3-dots indicator when a secondary `More` screen is active, pre-warmed the **More** drawer GPU layers for smooth first-open transitions, and added velocity-matched fling physics across all screens (including over the Network topology graph and Simulator course).
- **Smooth Android IME keyboard drawers**: Animated mobile bottom-sheet drawers above the Android virtual keyboard using single-shot GPU compositor `translate` synchronization while keeping the bottom navigation bar fixed.
- **Compact mobile Simulator boards table**: Optimized the **Simulated boards** table on mobile viewports (`<= 860px`) with LED-only power indicators, current firmware version display, and compact icon buttons for power toggle and board deletion.
- **Documentation & API specs**: Updated the OpenAPI 3.1 and AsyncAPI 3.0 specifications, split hardware and simulator API tags by platform, added Raspberry Pi 4 `2.4 GHz` Wi-Fi / Bluetooth LE coexistence guidance, and fixed Linux `70-slaprf-esp32c5.rules` `uaccess` ordering.

## Bug Fixes

- **Android APK WebView cache**: Configured the Android `WebView` host to bypass stale HTTP disk cache entries (`LOAD_NO_CACHE`) so upgrading the APK always loads the newly embedded web bundle immediately.
- **Linux BlueZ seen-device cache on disconnect**: Cleared cached BlueZ peripheral handles on disconnect and guarded closed fingerprint updates so consecutive Bluetooth Hub reconnects succeed without restarting the binary.
- **Mobile Signals 60 FPS scrolling & fine-tune inputs**: Eliminated scope frame drops while scrolling the mobile timer list during live telemetry, locked background page scrolling behind open modals/drawers, and restored normal caret placement when tapping numeric fine-tune fields.
- **Flasher USB port picker**: Ensured **Read config**, **Flash**, and **Erase** in **Flasher** always present the USB device selector modal in both Simulator and Portable modes.

## Downloads & Firmware Compatibility

- **App binaries**: Single-file executables for Windows (`amd64`), macOS (`arm64` & `amd64`), Linux (`amd64` & `arm64`), and Android (`arm64-v8a` APK).
- **XIAO ESP32-C5 firmware**: `slaprf-xiao-c5.bin` (USB Hub & Spokes) and `slaprf-xiao-c5-ble.bin` (Bluetooth Hub), wire protocol `v2` (compatible with `v0.0.8` through `v0.0.12` timers, no reflash required).
