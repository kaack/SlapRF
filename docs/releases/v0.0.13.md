### ✨ What's New

| Feature | What Changed |
| :--- | :--- |
| **Per-Event Tracks** | Every **Practice** session and **Race** now has its own **Track** tab and timing rules. |
| **LapRF Network & USB** | Split **LapRF 8-Way** into dedicated **Network** (`:5403`) and **USB** modes. |
| **Bluetooth Hub Controls** | Pair, reconnect, cancel, or forget a **SlapRF Bluetooth Hub** from **Network**. |
| **Headless Raspberry Pi** | Auto-enables LAN access and Bluetooth power when launched over SSH or `systemd`. |

---

### 🛠️ Improvements

- **Per-timer calibration** · Calibrate and fine-tune individual timers in **Signals**, with VTX channels on pilot pills.
- **Mobile tab swiping** · Bottom-bar swipe order, natural flick physics, and smooth **More** drawer animations.
- **Unified Network bar** · Inline timing system switcher, unified device picker, and RotorHazard login prompt.
- **Compact mobile Simulator** · Status LEDs and icon actions fit phone screens without horizontal scrolling.

---

### 🩹 Bug Fixes

- **Android** · App updates always load the fresh UI bundle immediately.
- **Linux BLE** · Fixed Bluetooth Hub reconnects failing after a disconnect.
- **Mobile Signals** · Fixed scroll stutter during live telemetry and numeric input cursor taps.
- **Flasher** · **Read config**, **Flash**, and **Erase** consistently open the USB port picker.

---

> [!TIP]
> **No reflash needed** · Existing `v0.0.8+` XIAO ESP32-C5 timers are 100% compatible with `v0.0.13`.  
> **REST API** · `/v1` hardware and track endpoints are now grouped by transport and session (`/docs/specs/openapi.yaml`).
